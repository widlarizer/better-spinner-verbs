# better-spinner-verbs

## Installation

In Claude Code:

```
/plugin install spinner-verbs --marketplace widlarizer/better-spinner-verbs
```

From a shell:

```
claude plugin install spinner-verbs --marketplace widlarizer/better-spinner-verbs
```

In the desktop app: + → Plugins → Add marketplace → `widlarizer/better-spinner-verbs` → Add plugin.
